## Codebase Patterns
- Supabase Storage: use service role key client in lib/supabase.ts; `createSignedUploadUrl(path, { upsert: true })` for overwrite-safe presigned upload URLs; `getPublicUrl(path)` for public read URL
- tRPC v11 + Next.js App Router: use `fetchRequestHandler` from `@trpc/server/adapters/fetch` in `app/api/trpc/[trpc]/route.ts`
- Clerk v7 auth in tRPC context: `const { userId: clerkId } = await auth()` from `@clerk/nextjs/server`
- tRPC protectedProcedure loads full user from Prisma and adds to ctx; access as `ctx.user` in procedure handlers
- tRPC frontend client: `createTRPCReact<AppRouter>()` in `lib/trpc.tsx`; Provider setup in `app/providers.tsx` with `httpBatchLink({ url: '/api/trpc', transformer: superjson })` + `ClerkProvider` + `QueryClientProvider`
- Sync server state to controlled form: use a `synced` boolean flag to copy query data into local state once on load, avoiding re-initialization on every render
- Prisma 7 has breaking changes: no `url` in datasource block; URL goes in `prisma.config.ts`
- `binaries.prisma.sh` (Prisma CDN) is unreachable in this environment; use custom schema engine
- Custom schema engine (`scripts/schema-engine.mjs`) handles all Prisma RPC + CLI calls
- The fake engine binary at `node_modules/@prisma/engines/schema-engine-debian-openssl-3.0.x` delegates to `schema-engine.mjs`
- SQL generation uses `@prisma/prisma-schema-wasm` `get_dmmf` with `{ prismaSchema: content }` param
- `prisma migrate dev` flow: devDiagnostic → applyMigrations(existing) → evaluateDataLoss → createMigration → applyMigrations(new)
- `createMigration` response uses `extension: 'sql'` (no leading dot) — WIe writes `migration.${extension}`
- `applyMigrations` response key is `appliedMigrationNames` (camelCase)
- PRISMA_SCHEMA_ENGINE_BINARY env var only affects CLI mode; daemon uses the binary from node_modules/@prisma/engines
- Schema-engine `@@index` regex is greedy — only captures LAST `@@index` per model; manually add missing indexes to migration SQL after generation
- Schema engine generates full CREATE TABLE/INDEX for all models each migration (not delta); `applyMigrations` ignores DDL errors on re-run
- Prisma: never mix `include` and `select` at the same query level — use only `select` with nested `select` for relations
- Cursor pagination: `take: limit + 1`, then `items.pop()` to get nextCursor; skip: 1 when cursor provided
- Stripe SDK: use `apiVersion: '2026-02-25.clover'` for stripe@20.4.1 (latest as of 2026-03)
