## Codebase Patterns
- Project source is at `autovagas/autovagas/` (nested), not at root. All source edits go there.
- Prisma migration history is corrupted: all 4 existing migrations try to create the same schema from scratch. Use `prisma db execute` + `prisma migrate resolve --applied` instead of `prisma migrate dev` for new migrations.
- Typecheck: run `npx tsc --noEmit` from `autovagas/autovagas/` directory.
- Prisma client regeneration: run `npx prisma generate` after schema changes.
